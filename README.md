# Hospital Emergency Room Analysis Dashboard – Excel

## Project Overview
This project focuses on analyzing hospital emergency room data through an interactive Excel dashboard. The objective is to help stakeholders understand patient visits, waiting times, satisfaction levels, admission patterns, and department referrals.

## Business Objectives
- Monitor the number of patients visiting the emergency room.
- Analyze average patient waiting time.
- Track patient satisfaction scores.
- Compare admitted and non-admitted patients.
- Understand patient age and gender distributions.
- Analyze patient timeliness and department referrals.

## Tools and Technologies
- Microsoft Excel
- Power Query – data import, cleaning, and transformation
- Power Pivot – data modeling
- DAX – calculated columns and analysis
- PivotTables and PivotCharts – reporting and visualization

## Project Workflow
1. Business requirement gathering
2. Understanding the dataset
3. Importing data using Power Query
4. Data cleaning and quality checks
5. Creating a calendar table
6. Building the data model using Power Pivot
7. Creating calculated columns using DAX
8. Developing PivotTables and charts
9. Designing the dashboard
10. Generating insights from the analysis

## Key Performance Indicators
- Total number of patients
- Average waiting time
- Average patient satisfaction score

## Dashboard Analysis
- Patient admission status
- Patient age distribution
- Percentage of patients seen within 30 minutes
- Gender analysis
- Department referral analysis
- Daily trends in patient visits, waiting time, and satisfaction

## Key Learnings
This project provides practical exposure to data preparation, data modeling, KPI tracking, dashboard design, and reporting using Excel analytics tools.
